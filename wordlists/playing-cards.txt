# The playing-card table — games, gambling, tarot, fortune-telling and sleight
# of hand. The Joker reads it: a word on this list adds to his total for good
# (JOKER_THEME in js/constants.js), and the thirteen card names on it pay their
# own value instead (JOKER_CARDS).
#
# Not a register list, so not named theme-*.txt: tools/theme-list.mjs treats
# those as the ×3 registers' lists and would strike these words from the pool
# the registers are read from. Check it by path:
#   node tools/theme-list.mjs check wordlists/playing-cards.txt
#
# Struck, because they were inflected from the wrong word: the list grew by
# taking each base's forms, and a base's forms are not all on the table. WINED,
# WINES and WINING are WINE's, not WIN's; STARING is STARE's, SKATING SKATE's,
# TENSED TENSE's, CUTEST CUTE's, WARES WARE's, DIED and DYING a death's, not a
# die's (and some forty like them). RAN, RANG, RUNG and TOLD went for the
# milder version of the same mistake: RUN, RING and TELL are on the table as
# nouns (a run of cards, a ringer's ring, a poker tell), and these are only the
# verbs. PASSED, SUITED and GAFFED stay; they are what they look like.
#
# Some entries are not in the dictionary (BEZIQUE, PIQUET, TAROCK and about
# ninety more). They are harmless: a list entry only counts once the dictionary
# lets the word through, so they wait here until it does.
