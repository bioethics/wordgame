# Borrowed names — the gods, saints, places, stars and characters in books
# that parents name children after. The Expectant Parents vouch these beside wordlists/names.txt
# and pay for them the same way; the two are one register to the player.
#
# Kept apart from names.txt for two reasons. That file is GENERATED from the US
# and England & Wales birth charts (tools/build-names-list.mjs), so anything
# added to it by hand would be lost on the next rebuild; and The Generic borrows
# a name from it for every copy, where "Doreen the Nondescript" is the joke and
# "Quetzalcoatl the Middling" is a different one. This file is written by hand.
#
# Names here are left out of this file when the charts already hold them (PARIS,
# ATHENA, SYDNEY, FREYA are in names.txt), so the two never disagree about a
# word. The rule for what belongs: a country, a region, a city a reader would
# know, a god or a figure of myth, a saint, a character in a book a reader
# would know, a body in the sky. A saint or a character goes in by the name
# they are known by, surname or not: AQUINAS, BECKET, HOLMES, KARENINA.
#
# Struck on purpose, because the everyday word swamps the name and would turn
# the +15 on for ordinary play: TYRE, CANTON, OPS, BALDER (more bald; BALDR
# and BALDUR stay), ARCTIC, MALE (the Maldives' capital), MORE and FISHER (the
# two English martyrs), HERO (Much Ado's), and BOO and ROO, which are three
# easy letters each. FANNY, because in British and Australian English the
# everyday word is rude. Left out altogether: SHYLOCK and FAGIN, whose names
# carry their authors' antisemitism into the language.
#
# Kept although they are also words, because the name is the first reading or
# the set is a promise (every one-word country counts): OXFORD, MERCURY, MARS,
# MEDUSA, TURKEY, CHILE, GUINEA, PANAMA, COLOGNE, VALENTINE, HAMLET, SCROOGE,
# SCOUT, PUCK, PIP, POOH.
# Anything matching a barred word is struck at load, as for every list.
#
# Spellable only: A to Z, two to twelve letters, so QUETZALCOATL just fits and
# HUITZILOPOCHTLI does not. One name per line; # starts a comment.
