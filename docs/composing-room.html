Plugging it in

One script, one global. The game calls four things; the band does the rest, including the join between moods (a ii–V pivot on the next bar line, tempo drifting toward the new one).

// index.html
<script src="js/music.js"></script>

// the first call has to come from a click or a keypress (browser rule)
Music.start('workshop');

// wherever the scene changes
Music.setMood('market');        // 'workshop' | 'calm' | 'market' | 'blackmarket' | 'editor'

// off-grid remarks, spelled in the current key
Music.cue('good');             // 'good' | 'bad' | 'hire' | 'page' | 'turn'

Music.setVolume(.7);  Music.setPatina(.4);  Music.modulate();  Music.stop();
Music.on('bar', info => …);   // key, chords, chart, tempo — what this page draws from
