The voices that were already there

These had a voice before this audit, and nothing above duplicates them. Scoring in particular was richly scored already; the gap was almost entirely in the quiet minute before you press Print. One was changed: the Testing Chamber's tabs used draw() as a stand-in for a page turn, and now use page() like every other view change.

  • Drawing and landing a tile — draw, land
  • Tiles flying to the pile — discard, file
  • Each tile paying out, up the scale — tick
  • A colour lighting — chime
  • ×Mult engaging — mult
  • A patron leaning in — aura
  • Coins — coin; a refund or a return — gain
  • The press winding and coming down — crank, total
  • Page cleared — win; run lost — lose
  • A word refused, an editor taking the desk — bad
  • A tile burnt — burn
  • Buying, selling, rerolling, Colophon picks, Chamber tabs
  • Binning a sundry at the bench — discard
